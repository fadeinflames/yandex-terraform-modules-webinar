# instructor/: материалы лектора

Эта папка **не публикуется** в `main`: в `.gitignore` публичной ветки стоит `/instructor/`.
Храните её в приватной ветке `instructor` (или в приватном репозитории рядом) и не мёржите в `main`.

| Файл / папка | Что это |
|---|---|
| `reference-solution/` | Эталонное решение ДЗ (базовая часть) |
| `quick-check.sh` | Быстрая проверка присланной работы |
| `review-checklist.md` | Чек-лист ревьюера, рубрика, типичные замечания |
| `prep-checklist.md` | Подготовка к вебинару и уборка |
| `bootstrap-state-bucket/` | Бакет и сервисный аккаунт под remote state для демо |
