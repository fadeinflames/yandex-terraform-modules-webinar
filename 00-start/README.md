# 00-start: плоский стартовый проект

Стенд целиком в одном `main.tf`: сеть, security group, диск, ВМ с nginx.
Это **исходная точка рефакторинга** для демо и домашнего задания: слабые места помечены комментариями «БОЛЬ №N».

```bash
cp terraform.tfvars.example terraform.tfvars   # подставить значения
terraform init && terraform apply
```

Здесь токен лежит в `terraform.tfvars`: так проще начать, но так делать нельзя. Сегодня мы от этого уходим.
Не коммитьте `terraform.tfvars` и `terraform.tfstate`.

## Если `terraform validate` падает на `file("~/.ssh/id_rsa.pub")`

Это **БОЛЬ №6** в действии: путь к ключу вшит в код и подходит только машине автора. Если ваш ключ называется иначе
(например, `~/.ssh/id_ed25519.pub`), поправьте путь в `main.tf` или создайте ключ: `ssh-keygen -t ed25519`.
В домашнем задании вы вынесете путь в переменную, и проблема исчезнет.

После `terraform init` появится `.terraform.lock.hcl`: в своём проекте закоммитьте его (здесь он намеренно не закоммичен, это БОЛЬ №3).
